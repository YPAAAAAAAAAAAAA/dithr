# dithr

A clean-room, from-scratch re-implementation of the idea behind **[redphx/dithr](https://github.com/redphx/dithr)** by [@redphx](https://github.com/redphx). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
